# Code of Conduct

We want this project to be a respectful place for evidence-focused collaboration.

Participants must communicate constructively, critique claims rather than people, respect privacy boundaries, and avoid harassment, discrimination, threats, or deliberate disruption. Do not post credentials, private repository content, personal contact details, or confidential material.

Maintainers may edit or remove content that violates these expectations and may restrict participation when necessary to protect contributors or the project. Report sensitive conduct concerns through the same private channel described in [SECURITY.md](SECURITY.md); do not publish personal details in an issue.
