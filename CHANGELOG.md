# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-11

### Added

- Read-only scans of public GitHub repositories.
- Separate repository, adoption, activity, community-health, and maintainer-context views.
- JSON and Markdown output with bounded-count disclosures.
- Optional collaborator-permission verification through `GITHUB_TOKEN`.
- Standard-library-only runtime, synthetic tests, and GitHub Actions CI.
